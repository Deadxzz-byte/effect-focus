Effect Focus

Protótipo de aplicativo de conversas com tema espacial: servidores, canais de texto e voz, mensagens diretas, cargos com hierarquia, perfis com foto e banner (incluindo GIFs), emojis e figurinhas animadas, e bots com personalidade.

Demonstração: https://Deadxzz-byte.github.io/effect-focus/

Status

Este é um protótipo. Tudo roda no navegador:

contas, servidores e mensagens ficam salvos só no navegador de cada pessoa;
não há conversa real entre pessoas, e as calls são simuladas;
os bots respondem com regras simples (a IA só funciona dentro do Claude);
o compartilhamento de tela mostra a tela só para você.

Para virar um serviço de verdade, faltam servidor com contas seguras, chat em tempo real, voz por WebRTC e moderação.

Como usar

Abra o index.html no navegador, ou acesse a demonstração acima. Não há nada para instalar.
